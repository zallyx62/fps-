# RIXE — third-party notices and licence scope

This file defines the exact scope of the RIXE source-available licences and identifies material governed by other terms. It is a tracking document, not legal advice. Before redistribution, check `LICENCE_DISTRIBUTION.md` and the licence file applicable to the exact asset.

## 1. Original RIXE software — PolyForm Noncommercial 1.0.0

The root `LICENSE` applies only to original software/source code whose necessary rights are owned or controlled by the RIXE rights holder:

- Original RIXE Python, DSL and validation/generator source files in `Tools/**` (not generated art exports, installed packages, or third-party components).
- Original game logic Blueprints in `Content/Rixe/Blueprints/**` and `Content/Rixe/Weapons/Blueprints/**`, only after their provenance and dependencies are verified.
- Original input/action mapping assets in `Content/Rixe/Input/**`, only after provenance is verified.
- Original UI logic Blueprints matching `Content/Rixe/UI/WBP_*.uasset`, only after provenance is verified.
- Original source-code files in `prototype-web/**` (for example HTML/CSS/JavaScript), excluding image, audio, font, model and other artistic files.

PolyForm is not being used here as a blanket licence for artwork, documents, Unreal Engine, Epic content, third-party plugins, third-party dependencies, or unverified material.

## 2. Original RIXE artwork and written documentation — CC BY-NC 4.0

`LICENSE-ARTWORK.md` identifies the Creative Commons Attribution-NonCommercial 4.0 International licence. It applies only to original, rights-cleared artwork and written works made by or for RIXE, including:

- Original meshes, models, textures, materials, weapon skins, UI textures, illustrations, animations, sound effects, music and other artistic works, but only where their asset-specific provenance is verified.
- The current candidate artwork paths are `Content/Rixe/Materials/**`, `Content/Rixe/Meshes/**`, `Content/Rixe/Weapons/Materials/**`, `Content/Rixe/Weapons/Meshes/**`, and `Content/Rixe/UI/T_*.uasset`. These are candidate paths, not a declaration that all files in them are already rights-cleared.
- Original written documentation in root-level Markdown files and `spec/**`, including the cahier des charges, where copyright is held or controlled by the rights holder.
- Original separately committed exports (for example OBJ/PNG) generated by RIXE tools, only when they are original and rights-cleared.

CC BY-NC 4.0 permits noncommercial copying, sharing and adaptation with appropriate attribution, a link to the licence, and an indication of changes. It does not grant commercial-use rights. The rights holder retains the ability to grant a separate written commercial licence for rights they actually own or control.

The suggested attribution is in `LICENSE-ARTWORK.md`. Record asset-specific authors and attributions where different. Do not apply CC BY-NC to software source code; Creative Commons recommends software-specific licences for software but says CC licences may be used for separate game art/music and documentation.

## 3. Unclassified or mixed Unreal assets

Do not assign either RIXE licence by directory name alone. The following remain excluded until their content and dependencies have been inspected and classified:

- `Content/Rixe/Maps/**`, including `Lvl_RixeRange.umap`, because a map may combine RIXE-authored layout, Blueprints and Epic/third-party assets.
- `Content/__ExternalActors__/**` and `Content/__ExternalObjects__/**` until each actor/object is traced to its map and dependencies.
- Any `Content/Rixe/**` file not explicitly classified above.
- Any asset containing or derived from Epic or third-party material, unless the applicable licence permits the exact use and redistribution.
- Any work created by a contributor until the contributor's rights and written grant/assignment have been checked.

A file being stored in a RIXE directory does not prove that it is original, authored by the owner, or rights-cleared.

## 4. Epic Games and Unreal Engine

Official terms to check at the time of each release:

- Unreal Engine EULA: https://www.unrealengine.com/eula/unreal
- Epic Content License Agreement: https://www.unrealengine.com/eula/content

The repository is based on the Unreal Engine 5.8 "First Person / Arena Shooter" template. The EULA defines "Examples" as code, artwork, or other content made available in the installation's Samples and Templates folders. Section 5(b) permits distribution of Examples, including modified Examples, in source or object code to third parties. This permission is usable only after the exact source/provenance of each included asset is verified against the installed engine version and the EULA definition.

The current repository contains Epic/template-derived folders, including:

- `Content/Characters/**`
- `Content/FirstPerson/**`
- `Content/Input/**`
- `Content/LevelPrototyping/**`
- `Content/Variant_Shooter/**`
- `Content/Weapons/**`
- `Content/__ExternalActors__/**`
- `Content/__ExternalObjects__/**`

These paths are a provisional inventory, not proof that every file is an Epic Example. Map-generated external actors/objects and any files copied from other packs must be traced to their actual source. Keep all Epic notices. Do not apply PolyForm or CC BY-NC to these files.

Unreal Engine code and Engine Tools are not licensed by RIXE. Do not commit engine source or redistribute Engine Tools outside the channels permitted by the EULA. When a distributed game incorporates Licensed Technology, Epic's EULA requires it to be included in object code as an inseparable part of the Product and requires the applicable end-user licence/disclaimer. Do not package Epic source assets separately.

The Unreal Engine EULA's Non-Compatible Licenses clause (section 6(c)) names GPL, LGPL (subject to its stated exception) and CC BY-SA as examples. It does not name PolyForm Noncommercial or CC BY-NC 4.0. This is not express Epic approval of either licence. The separation described here is intended to keep Epic technology under Epic's own terms, RIXE software under PolyForm, and separate RIXE art/documentation under CC BY-NC. Compatibility of the actual combined project still requires written Epic clarification or qualified legal review before definitive clearance.

## 5. Epic Marketplace, Fab, Learn, and Quixel content

Content downloaded through Fab/Marketplace, the Learn tab, or Quixel is governed by its own Epic Content License Agreement or the licence shown for the item. The content agreement generally allows distribution to end users only as object code inseparably incorporated into a project and generally prohibits public source redistribution of the licensed content.

The Marketplace Distribution Agreement defines a "Prohibited License" to include terms requiring material to be redistributable at no/minimal charge or only for non-commercial purposes, and prohibits submitting content that contains material under such a licence or derivatives of it. PolyForm Noncommercial and CC BY-NC are therefore not to be used for a Fab submission. **Do not submit RIXE material under either licence to Fab unless Epic has given written permission or the submission has been restructured and legally cleared.**

No Fab, Learn, or Quixel asset is currently declared as cleared for public source redistribution. Before using one, record its name, source URL, exact licence/version, acquisition date, attribution, and permitted redistribution format here. Do not commit the raw asset to the public repository unless its licence explicitly permits that distribution.

## 7. Python tool dependencies

`Tools/requirements.txt` currently lists `numpy`, `scipy`, and `Pillow`. They are installed by the user and are not intentionally vendored by this repository. Record exact versions and licences before bundling any of them into a distributed tool.

## 8. Shared official game and cosmetic content policy

The official RIXE release must provide the same base-game content and the same official cosmetic catalogue to all players. No paid-exclusive skin, paid cosmetic advantage, platform-exclusive catalogue, or region-exclusive official skin is permitted. Official cosmetics use the same availability and unlock rules for everyone. Local graphics presets may scale rendering for hardware performance, but must not withhold game content or create a competitive gameplay advantage. This is a product rule and does not change third-party asset licences or guarantee identical pixels across different hardware.

## 9. Release evidence still required

Before public release of a source snapshot or packaged game:

- Complete a file-level provenance inventory for `Content/Rixe`, all template folders, external actors/objects, plugins, tools, fonts, sounds, textures, animations, maps and imported resources.
- Verify that every Epic-derived source asset in this public repository is an EULA "Example" covered by section 5(b), or remove/isolate the file and document an alternative workflow for contributors to obtain it under their own Epic licence.
- Confirm that every item under PolyForm and CC BY-NC is rights-cleared, correctly classified, credited and marked with the appropriate licence; identify third-party contributors.
- Verify plugin licences and target inclusion; preserve all required third-party notices.
- Check that the exact packaged build distributes Epic Licensed Technology only in permitted format and includes the required end-user terms and credits.
- Obtain written Epic clarification or qualified legal review of both RIXE licence scopes and the Unreal EULA 6(c) interaction.
- Recheck Epic's current terms and the exact release artefact immediately before release.

Do not state that Epic has approved either RIXE licence or that all assets are cleared until the evidence above exists.
