## How to maintain the specification

```
python Tools/split_spec.py split   # writes spec/ (one file per section) and spec/INDEX.md
python Tools/split_spec.py check   # parts must equal the single file
python Tools/split_spec.py join    # rebuilds CAHIER_DES_CHARGES_RIXE.md from spec/
```

Once the owner approves, edit only `spec/*.md`, run `join` before committing, and update `CLAUDE.md` (section 1) to say the parts are the source. This lets an agent read one section instead of 338 KB.

## LFS

- GitHub Free includes 10 GiB of LFS storage and 10 GiB of bandwidth per month. With a spending budget of $0, going over blocks LFS until the next month; nothing is charged.
- Clones, pulls and forks count against the owner's bandwidth. The `Validate` workflow does not fetch LFS files.
- Decide with a number: run `git count-objects -vH`. If the repo is under about 1 GB and no file is over 50 MB, wait. Otherwise enable LFS early:
  `git lfs install` then `git lfs track "*.uasset" "*.umap" "*.ubulk" "*.uexp"`.
- Moving existing history into LFS (`git lfs migrate import`) rewrites history. `CLAUDE.md` forbids that without the owner's approval, so make a backup first.
- Procedural assets in `Tools/` (weapons) keep the repo light: commit the generator, not every export.
